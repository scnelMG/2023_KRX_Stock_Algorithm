# 재현 가능성 메모

## 현재 상태

이 저장소는 경진대회 당시 작업 흐름을 보존한 노트북 중심 구조입니다. 완전한 패키지형 프로젝트라기보다, 금융 시계열 예측 실험과 제출 파일 생성 과정을 확인하는 포트폴리오 자료에 가깝습니다.

## 실행 전제

- Python 3.x
- Jupyter Notebook
- pandas, numpy, scikit-learn, statsmodels
- `data/train.csv`와 제출 샘플 파일

## 권장 실행 순서

1. `[Baseline]_ARIMA.ipynb`
2. `window_slicing.ipynb`
3. 제출 CSV 생성 및 형식 확인

## 공개 제한

대회 원본 데이터와 제출 파일의 재배포 조건이 명확하지 않아, Drive 자료는 추가 공개하지 않았습니다. 재현성은 공개 가능한 설명과 노트북 흐름 중심으로 제공합니다.
