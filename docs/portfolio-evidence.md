# 포트폴리오 근거 정리

이 문서는 대회 당시 Notion 기록, 개인 보관 Drive의 파일 목록, 현재 공개 코드에서 교차 확인된 사실만 정리합니다. 없는 실험 결과나 역할 분담은 보완하지 않습니다.

## 확인된 대회 맥락

- 대회: 2023 제2회 KRX 주식 투자 알고리즘 경진대회
- 제출: 2,000개 종목의 순위
- 거래 가정: 상위 200개 Long, 하위 200개 Short를 같은 비중으로 거래
- 평가 기간: 예측 시점 이후 15거래일
- 최종 순위 기준: 대회가 계산한 Sharpe 지수

위 규칙은 [DACON 예선 평가 규정](https://dacon.io/competitions/official/236117/talkboard/408727?page=1&dtype=recent)에 기록돼 있습니다.

## 확인된 구현

| 항목 | 코드 근거 |
| --- | --- |
| 기준선 | `[Baseline]_ARIMA.ipynb`의 종목별 ARIMA(2, 1, 2) |
| 제출 파이프라인 | `window_slicing.ipynb` |
| 입력 | OHLCV, PER, PBR, 종목별 군집 피처 |
| window 길이 | 3거래일 |
| 예측 대상 | 1일·15일 뒤 종가 |
| 순위 기준 | 두 예측 종가로 계산한 기대수익률 내림차순 |

## 보관된 자료의 한계

Drive에는 실행 노트북, 제출 파일, 대회 데이터 폴더가 남아 있었지만, 발표 자료나 검증 결과표는 없었습니다. Notion에도 평가 규칙·아이디어·자료 조사만 남아 있으며 다음 자료는 확인되지 않았습니다.

- 최종 모델을 선택한 실험표
- 독립 검증 기간과 종목 단위 RMSE 집계
- 동일 기간의 모델별 Sharpe 비교
- 실제 서비스 화면 또는 발표 슬라이드

따라서 README의 리더보드 점수는 공식 결과로만 제시하고, 모델 성능 지표처럼 해석하지 않습니다.
