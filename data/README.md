# 데이터 공개 기준

## 포함 파일

이 폴더는 경진대회 데이터의 로컬 배치 위치를 설명하기 위한 자리입니다. 공개 브랜치에는 원본 학습 데이터, 샘플 제출 파일, 제출 후보 CSV를 포함하지 않습니다.

## 주의 사항

- KRX 대회 원본 데이터와 제출 파일은 재배포 조건이 명확하지 않을 수 있습니다.
- Google Drive에는 대회 폴더와 제출 파일 폴더가 확인되었지만, 추가 파일은 공개 저장소로 옮기지 않았습니다.
- 외부 제출용 포트폴리오에서는 원본 데이터 없이 실험 구조와 노트북 흐름을 중심으로 검토합니다.

## 리뷰어 안내

이 프로젝트의 평가 포인트는 원본 데이터 자체가 아니라, 시계열 window 구성, baseline 비교, 제출 파일 생성 흐름입니다.
