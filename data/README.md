# 데이터 경계

이 디렉터리는 공개 데이터 보관소가 아닙니다. 실행에 필요한 로컬 파일의 위치만 설명합니다.

## 공개 저장소에서 제외하는 항목

- 대회 원본 학습 데이터
- 대회 제공 제출 양식
- 생성된 제출 CSV
- PER·PBR 원본 또는 스냅샷

대회 Notion 기록에는 제공 자료를 이용 목적 달성 후 정해진 기한까지 파기해야 한다는 조건이 있습니다. 따라서 해당 자료를 이 저장소에 추가하거나, 보유 권한을 확인하지 않은 상태에서 다시 실행해서는 안 됩니다.

## 권한이 있는 후속 실험

보유·사용이 명시적으로 허용되는 경우에만 `train.csv`, `X_1st_year.csv`, `sample_submission.csv`, `fundamentals_snapshot.csv`를 로컬에 둡니다. 어떤 파일도 Git에 추가하지 않으며, 외부 공유 전에는 원본 약관을 다시 확인합니다.
